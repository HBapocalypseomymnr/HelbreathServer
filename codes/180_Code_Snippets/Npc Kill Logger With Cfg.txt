Files to edit : 4
Files to create : 1
Folders to create : 1


STEP 1 : Create the Logs Directory

Go to your HB Server root directory and create a new folder Called "NpcKillLogs".


STEP 2 : Create the Config File

Go to the "HB_Server/GameServers/GameConfigs/" and create a new file called NpcLogSettings.cfg. It must contains this

CODE  
monsters-log-type = ALL
kill-logger-mode  = ON 



Here are the aivable configs :
- monsters-log-type : ALL (logs all monsters), MIGHTY (logs Barlog, Ettin, Demon, Unicorn, Gagoyle, Centaurus, Giant-Lizard, MasterMage-Orc, Minotaurs, Nizie, Hellclaw, Tigerworm, Wyvern, Fire-Wyvern, Abaddon, Crops), BOSS (logs only Hellclaw, Tigerworm, Wyvern, Fire-Wyvern, Abaddon, Crops)
- kill-logger-mode : ON or OFF. Will activate or not the logging of npc kills
