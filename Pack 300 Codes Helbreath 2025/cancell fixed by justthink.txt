El bug del cancell consiste en que luego de recibir varias veces la magia, los efectos de las protecciones duran menos... Aca les traigo el fix.. testeado (bastante largo por cierto xD), anda 100%..

En la clase CGame deben agregar el siguiente metodo:
Código:
CDelayEvent *CGame::GetDelayEvent(int fromIndex, char ownerType, int iEffectType)
{
	for (int i = 0; i < DEF_MAXDELAYEVENTS; i++)
	{
		if (m_pDelayEventList[i] != NULL)
		{
			if ((m_pDelayEventList[i]->m_iTargetH == fromIndex) 
				&& (m_pDelayEventList[i]->m_cTargetType == ownerType) 
				&& (m_pDelayEventList[i]->m_iEffectType == iEffectType)) 
			{
				return m_pDelayEventList[i];
			}
		}
	}

	return NULL;
}
Este metodo, la funcion que cumple es la de devolver el puntero con la informacion del objeto Delay, que contiene el timer de la magia del cliente.. Teniendo esto lo unico que tenemos que hacer es modificar el timer de la magia cuando recibimos un cancell..
